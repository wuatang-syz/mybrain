# 知识地图设计与集成验收

状态：自动化验证通过；真机截图与运行时断言等待在 Obsidian 中重跑（见文末步骤）。本次重构替换了旧版的交错网格布局与 HTML 群落标签，旧截图 `output/knowledge-map-*-final.png` 不再代表当前实现。

## 圆角卡片 → 椭圆卡片（视觉修复）

第一版卡片上线后，真机表现暴露两个问题：节点胶囊丢色（原生图谱给每个节点施加 tint，把我们的填充色乘掉了），以及卡片框、连线、进入按钮、标题整体不显示（它们画在一个后加的辅助 PIXI 图层上，该图层在真机里没有出现在画面上）。

处理方式：

1. 节点渲染时重置 `circle.tint = 0xffffff`，恢复群落配色。
2. 删除辅助图层，卡片框、结构边、跳转边、引用边、进入按钮、折叠箭头全部改由**原生节点自己的绘图表面**绘制；群落标题复用主题节点自己的文字对象（屏幕等尺寸，浮在椭圆上方）。绘制失败不再静默，会通过 `takePaintError` 报到画布顶部提示条（“知识地图绘制失败：…”）。
3. 卡片改为椭圆：椭圆按内容块外接要求放大（×1.5），节点网格居中，主题节点是实心椭圆“群落头”，一级子节点是椭圆胶囊，更深成员是圆点（悬停显名）。
4. 折叠与进入：卡片右上角分别是折叠箭头（`+N` 篇折叠时向下、展开时向上）与进入按钮，均为屏幕等尺寸，带悬停提示；成员数量在状态栏与悬停提示中给出。

复核要点：卡片是否呈椭圆且互相留白清楚、节点是否恢复彩色、标题与进入按钮是否可见、拖动节点时椭圆是否跟着扩、拖动椭圆是否整组移动。

## 本次重构

1. 群落改为强分区卡片：卡片 = 注意层的一个直接子节点，叶笔记同样成卡；卡片是圆角底 + 边框，标题、计数、“+N 篇”和“进入”按钮浮在卡片上方，按屏幕像素固定尺寸，缩放时始终可读。
2. 注意层笔记不再画在画布上，只在顶部根节点栏展示；点击可选中并打开右侧笔记，点击上级可返回上一层。
3. 布局改为确定性卡片打包：按主题路径稳定排序、按画布宽高比换行，卡间距 44、画布边距 80；节点拖出卡片时卡片实时扩张包住它，拖动卡片则整组移动；窗口尺寸变化只重算布局，不再自动重排 + 适应画布。
4. 连线分层：结构边只在卡片内部，跳转边为次要细线，普通双链默认隐藏、选中或悬停时展开并压暗其他卡片，去掉了跨画布的长扇形曲线。
5. 交互修复：单击立即选中并同步右侧笔记（去掉 280ms 延迟），拖动与点击用 4px 位移阈值区分，Esc 取消拖动；命中测试改为屏幕坐标，缩放后仍可点中。
6. 旧版 `mapLayout`（散乱自动坐标）在升级时整体重置为新版卡片结构；新增 `mapAttention` 保存当前层级，失效时回退到全局根。
