# 原生图谱融合

Brain 主视图使用 Obsidian 已注册的 `graph` 视图工厂，取得原生数据引擎、PIXI 渲染器和 Graph Worker。当前视图内只有一个原生图谱渲染器；没有独立的外围布局、DOM 结构图叠层或第二个画布。

## 分工

- 原生图谱负责圆点、力导向、搜索筛选、颜色分组、标签/附件/孤立节点开关、缩放和时间演示。
- Brain 在同一个 PIXI hanger 中修改当前结构节点的形状，使用四向布局。拖动节点主体到同组节点上可调整顺序：被拖节点半透明跟随指针，同组节点让出空位，空位处显示虚线落点框；松手后短动画落入新位置并保存顺序，拖到空白处或按 Esc 取消。中心节点不参与排序。顺序按当前中心笔记保存，刷新、折叠再展开和重新打开后恢复；四向连接点仍用于编辑关系。
- Brain 通过单实例节点/边方法适配添加连接端点和结构连线，不修改原生类的全局 prototype，也不改写 Obsidian 安装文件。
- 缩放、适应画布由主视图持有的共用底部控件承载（`src/ui/footer-controls.ts`），与知识地图使用同一组件；画布只提供动作和当前缩放比例。
- 从导图、关系图谱或知识世界打开笔记时，共用当前 Brain 标签右侧的同一个笔记标签；没有右侧分屏时才创建。首次识别这对分屏使用左侧 3/5（60%）、右侧 2/5（40%）宽度，后续笔记切换保留手动调整。已有右侧空标签、固定笔记和插件重载后的笔记标签均可复用；不会跳到其他分组中恰好打开同文件的标签。
- 打开请求串行执行，连续重复点击不重新加载同一文件；快速 A→B→A 切换保留最后一次选择。编辑入口先把目标加载到同一右侧标签，再打开现有编辑弹窗。关闭或移走右侧标签后，下次打开重新寻找/创建右侧分屏。
- 目录操作和新增内部链接由共享事务服务负责；跳转连线菜单打开实际来源笔记编辑。
- 原生搜索结果是显示范围的上限。关系合并只添加已显示端点之间的连线，不强行恢复过滤掉的节点。
- 自定义结构线使用 Brain 的布局和配色；原生节点尺寸等显示设置仍控制圆点。
- 关联节点复用同级节点的行高、间距和整行滚动逻辑，最多同时显示七行。左侧关联卡片右边缘对齐并以当前中心节点垂直居中；右侧同级卡片左边缘对齐并以父节点垂直居中。
- 同级与中心到关联的常规连线使用平滑曲线。左、右列内部跳转、跨列跳转，以及关联笔记到父文件夹的目录线使用外围直线通道；父文件夹即使出现在同级列，也从卡片外侧接入外围。端点随原生拖动与排序动画更新，适应画布包含外围通道与数量标识的空间。
- 同级数量显示在右侧竖向滚动条右侧中间；子级数量在横向滚动条下方中间；关联数量在左侧竖向滚动条左侧中间。数量标识只在对应滚动条实际显示、且分组标签设置开启时出现；关联滚动条位于关联区域左侧。
- 父子与中心直接关系保持清晰，其他关系常驻淡显。悬停、连接点悬停或已有节点选择会增强该节点的直接关系，其他线仍可见；指针离开恢复默认层次。每条连线保留对应的关系上下文菜单。

## 兼容边界

在 Windows Obsidian **1.13.7**（安装器 1.7.7）完成运行时验证。内部接口不是公开 API，后续 Obsidian 版本需要继续适配。

适配入口在 `src/ui/native-graph/types.ts`：`app.viewRegistry.viewByType.graph`、`view.renderer`、`view.dataEngine`。接口缺失时显示明确的不可用提示和重试按钮，不退回模拟图谱。请保持「关系图谱」核心插件启用。

关闭 Brain 会清理节点/连线装饰、监听器、搜索队列、原生视图以及 Worker。原生图谱选项沿用 Obsidian 原生保存机制。

## 验证

- 自动测试覆盖原生数据不被修改、搜索过滤不被绕过、结构布局不计算外围位置、四向端点语义、取消操作及自动跟随防重入。
- 在真实 Obsidian 中用原生 canvas 的指针事件验证：圆点打开笔记；节点本体拖动不创建；四个端点分别创建父级/子级/跳转/同级；外围连接端点连接到结构端点；原生缩放与搜索过滤；单一 Brain 渲染表面。
- 指针回归时替换业务回调以记录请求，不实际创建或修改用户笔记；关系持久化和撤销由已有服务测试覆盖。
- 每次源代码更新运行 `npm run sync`，随后通过 Obsidian CLI 的 `plugin:reload id=obsidian-brain` 重载并检查 `dev:errors`。

浏览器预览通过内存知识库适配器复用正式索引器和目录事务服务；实际原生渲染效果同时在 Obsidian 内验证。

当前模型：文件夹提供父子关系，所有原生笔记内部链接提供常驻跳转线；同名文件夹与笔记分开显示。孤立统计使用全库入链与出链，详见 [目录层级与双链关系](directory-hierarchy.md)。
