# 知识世界（第三个视图）

Brain 的第三个视图是可配置的**知识世界**：同一个知识快照由不同主题渲染成不同的三维世界。视图内部标识仍是 `map`，思维导图、关系图谱、笔记编辑器和关系操作都没有变化。

数据流是固定的四步：**笔记关系 → KnowledgeSnapshot → 主题映射与布局 → 三维呈现**。主题只能读取快照，不会自己扫描笔记。

## 知识快照

`src/world/snapshot.ts` 把现有知识逻辑（`knowledgeMap` / `mapDrawable`）包成快照：当前层、领域分组、笔记、真实关系与统计。快照里没有颜色、坐标、材质和世界名称，两种主题拿到的是同一份结果：

- 当前注意层笔记是**世界中心**，直接子笔记是**领域**（分组），领域内的笔记按结构归属分组，多父级笔记沿用既有的确定性归属。
- 每个笔记带 `depth`：相对世界中心的结构深度。跳转与普通双链不参与深度计算。
- 所有笔记保留真实目录归属，不创建合成的未归类分组。
- 展开预算与搜索可达性仍由公共知识逻辑决定：每卡最多展开 60 篇，全局受画布节点上限约束。深层笔记默认折叠，展开后按各自深度取造型。

## 层级阶梯

世界对象按深度取阶梯造型，索引是 `clamp(depth, 0, 14)`，第 12-14 级都是「点」。

| 深度 | 知识宇宙 | 知识城市 |
| --- | --- | --- |
| 0 | 知识晶核 | 中心广场 |
| 1 | 星系 | 分区 |
| 2 | 行星 | 街区及地标建筑 |
| 3 | 浮岛·基地 | 街区内的独立建筑 |
| 4 | 空间站 | 地面街区网格 |
| 5 | 光球 | 独立房间 |
| 6-14 | 八边形 → 七边形 → 六边形 → 五边形 → 四边形 → 三边形 → 点 → 点 → 点 | 同左 |

第 6-14 级是共用尾部（`POLYGON_POINT_TAIL`），两种主题降级方式一致，后续主题可以直接复用。所有造型都是程序生成的几何体（`src/world/shapes/`），「点」也是可射线拾取的小网格，因此选择、拖动、标签和搜索定位始终可用。层级名称会出现在世界设置的造型列表、进入按钮（宇宙「进入星系」/ 城市「进入分区」）和标签提示里。

## 主题定义

`WorldThemeDefinition` 统一声明主题的名称、阶梯、角色默认造型、视觉参数、布局策略、关系样式、界面文案与动效（`src/world/themes/`）。首版有两个主题：

- **知识宇宙**（默认）：沿用原有深蓝星云、晶体观测站、环状星球、光束连接和星场。
- **知识城市**：未来夜景都市。深蓝夜空下，中心信标塔、分区建筑群、地标塔楼、独立建筑、地面网格与房间全部由几何体搭建；立面用合并的水平灯带表示亮起的楼层，屋顶灯带、道路边缘灯与中心信标提供动效。

城市建筑按笔记 ID 生成稳定的变体：阶梯塔楼、双塔、裙楼与屋顶造型在刷新、搜索和切换主题后保持一致。金属框架、玻璃立面和冷色窗灯合成少量合并网格（按距离切换细节层级），不为每扇窗创建灯光，也不引用任何网络资源。

装饰（宇宙轨道环、城市道路）与真实关系分开处理：装饰只随主题动效更新，不可选中、不参与命中与布局。目录父子关系和内部链接形成的跳转线均常驻显示，两个主题使用同一关系快照。

## 配置

顶部工具栏在三个视图中完全一致（根节点栏、搜索、模式切换、更多操作），不承载任何世界专有控件。世界自己的操作收在画布右上角、搜索图标正下方的竖排图标栏里（`src/ui/world-actions.ts`），三个按钮都是图标：

- **切换世界主题**：循环箭头图标，展开主题列表（当前主题高亮），点选即换世界。
- **世界设置**：打开或关闭设置抽屉，抽屉本身也挂在画布内部、图标栏左侧。
- **暂停动效 / 开启动效**：图标在暂停与播放之间切换，状态写入外观 · 动效。

设置抽屉包含三个页签，标题栏、关闭按钮与「应用 / 取消 / 恢复主题默认」操作固定可见：

- **外观**：背景色、领域色板、标签大小、模型大小、动效、辉光，以及主题专有参数（城市还有窗灯亮度、地面与建筑配色）。
- **布局**：领域间距、成员间距，以及当前层的「重置布局」。
- **对象**：按中心、领域、笔记设置内置造型（默认「跟随层级（自动）」），再为具体领域或笔记覆盖颜色、图标和造型。

覆盖按字段合并：对象设置优先于角色默认，领域颜色默认传给成员，成员可以单独覆盖；造型覆盖限定在当前主题和角色内；笔记下钻成为中心时使用中心造型。

所有改动都是草稿：普通调整、城市外观参数、「恢复主题默认」和「重置布局」都会即时预览但不会写入，只有「应用」保存；「取消」、Esc、关闭按钮、切换主题或离开当前层都会完整回滚。Esc 关闭后焦点回到「世界设置」按钮，页签支持方向键、Home 与 End 切换。

拖动语义由主题提供：宇宙沿当前相机平面拖动，城市沿地面拖动；拖动领域带动成员，拖动笔记只改自身位置。配色与造型调整保留手动位置，布局参数只影响自动位置，手动位置优先。

拖动默认关闭：只有「调整布局」处于开启状态时才会移动对象，拖动领域带动成员，拖动笔记只改自身位置，Esc 取消本次拖动。设置面板处于预览中时拖动不会写盘。

## 探索交互

世界以场景为主，界面按需出现：

- 全景常驻中心与领域的简洁名称；数量、成员标题与操作只在悬停、键盘焦点、选中或足够近的缩放层级出现。标签避让搜索、图标栏与设置抽屉。
- **单击**模型或标签立即选中并高亮，350ms 后平滑聚焦并打开笔记；**双击**有子级的对象进入下一层，叶子笔记没有下一层，双击不跳转。模型与标签使用同一套判定，拖动不会触发点击。
- 选中节点不再显示底部操作卡。文件夹与笔记分别显示，孤立笔记仍位于自己的真实目录。左下角导航已移除。
- 画布左上角提供「返回上层」「全景」「调整布局」。搜索只定位并选中，不直接打开编辑器。
- 每层的镜头、展开与选中状态分别记录：进入与返回都会恢复该层原来的观察位置和选中对象，手动操作会立即中断镜头动画。关闭动效或系统要求减少动态效果时直接切换，不做过渡。

## 状态与迁移

知识世界与思维导图、关系图谱共用右侧笔记标签和串行打开队列，点击不同笔记替换右侧内容，不新增笔记标签。首次建立或识别分屏默认左侧 Brain 3/5（60%）、右侧笔记 2/5（40%）；同一对分屏后续打开保留手动调整。编辑操作也先复用该笔记标签。

`BrainData.knowledgeWorld`（版本 1）保存当前主题、每主题配置，以及按「主题＋注意层」区分的镜头、位置和展开状态。`mapAttention` 与 `mapSelected` 继续作为共用导航状态。

- 切换世界保持画布挂载与 WebGL 渲染器，只替换主题场景资源；保留当前层与选中笔记，恢复目标世界对应层的视角，没有记录时自动适应画布。外观调整不重新扫描笔记。
- 首次读取时，旧 `mapLayout.universe` 会幂等迁移到宇宙对应层的视图记录；旧二维数据、Markdown 与关系字段都不修改。
- 文件和文件夹重命名会同步迁移所有主题中的笔记引用；删除后清理失效引用，清理只在索引首次就绪后执行。
- 未知主题回退宇宙，非法配置字段逐字段恢复默认，主题加载失败保留当前可用场景并提示重试。配置与资源全部本地运行，没有网络请求。

## 验证

`npm run sync` 会依次运行测试、ESLint、类型检查、构建，并把 `main.js`、`manifest.json`、`styles.css` 同步到配置的 Obsidian 插件目录。同步后重新打开 Obsidian 或重载插件即可看到两种世界。

本机预览复用同一个生产组件：

```powershell
node scripts/export-universe-preview.mjs
node scripts/preview-universe.mjs
```

预览地址 http://127.0.0.1:5186/ ，只绑定回环地址，笔记读取受导出记录与路径边界约束。验收记录见项目根目录 `design-qa.md`；旧的原生二维地图说明保留在 `docs/knowledge-map-native-legacy.md`。
