# 国内买断上线操作

## 当前实现边界

全部功能付费。未激活时仅注册购买/激活入口和设置，不启动索引、关系迁移或图谱编辑。激活验证 P-256 签名后保存授权，重新启用插件后生效。无订阅、无联网授权、无设备绑定、无自动退款吊销。永久离线授权不能远程撤回；授权码可复制，不能承诺强防盗版。

微信、支付宝按钮打开配置的 HTTPS 托管收银台或购买说明页。**本项目尚未接入支付 API，也不会自行确认付款。** 不把回跳页面、截图或客户端参数视为付款依据。当前可用的是人工核实商户后台到账后签发授权的流程。

## 配置

编辑 `src/licensing/config.ts` 的 `wechatUrl`、`alipayUrl`、`priceLabel`、`support`。价格必须与收银台一致，页面需明确一次性买断、交付方式、售后联系方式和退款条款。不要把商户私钥或 API 密钥放进插件。公钥已配置，私钥保存在开发机项目目录之外。

新环境生成密钥（首次生成；不要覆盖已发行授权的旧密钥）：

```powershell
node scripts/license-admin.mjs keygen C:/private/mybrain-signing.pem
```

把输出的公钥填入配置。私钥仅限运营者访问，并做加密备份。丢失私钥无法继续用相同公钥签发新授权；更换公钥会使旧授权失效。

确认商户后台实际到账后发码：

```powershell
node scripts/license-admin.mjs issue C:/private/mybrain-signing.pem VERIFIED-ORDER-REFERENCE C:/private/order-license.txt
```

该命令只签名，**不验证订单是否付款**。必须在私有订单台账中记录订单号、授权码、交付情况；重复交付同一订单时使用已保存的码。通过客户购买时指定的渠道交付授权码。不要把客户台账提交到 Git。

## 自动收款发码的下一阶段

确定微信/支付宝商户产品或持牌托管支付平台后，在服务端实现建单、验签回调、核对金额/币种/商户及商品、去重、持久化订单、签名授权、订单查询与退款处理。发码私钥仅在服务端；回调验签算法依选定平台的官方 SDK。需要商户信息和部署地址才能完成真实端到端测试。

## 发布清单

- 运行 `npm run sync` 验证并同步当前开发知识库；本地仍使用 `obsidian-brain` ID，不迁移现有设置。
- 运行 `npm run package` 生成 `dist/themind`（不是收费上线确认）。
- 运行 `npm run release:check`，所有付款配置完整后才能通过。
- 核查源码权属、现有 LICENSE、第三方依赖及图片授权；保留原作者声明，不能仅删掉模板版权来实现闭源。
- 确认插件 ID `themind` 在官方目录唯一，核查最低 Obsidian 版本和原生图谱 API 兼容性。
- 在干净知识库手测：无授权不改笔记、有效/无效授权、重启持久化、离线使用、旧数据迁移，以及微信/支付宝各一笔真实支付与售后。
- 补充产品截图、商户主体、定价及退款条款后，创建 `0.2.0` GitHub Release，分别附加 main.js、manifest.json、styles.css，并按最新官方流程申请审核。当前未发布到 GitHub 或官方目录。

本次没有改变现有 LICENSE 的法律授权范围；在公开收费前必须确定最终授权方案。全功能支付门槛与源码许可是两个不同事项。
