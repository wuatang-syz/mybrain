# 知识地图

Brain 的第三个模式。画布使用同一个 Obsidian 原生图谱实例与 PIXI 渲染表面，右侧为 Obsidian 原生 Markdown 编辑分栏。无需外部服务，也不会为分组改写笔记。

## 共用界面组件

三个模式（思维导图、关系图谱、知识地图）除画布本身外共用同一套界面组件，由主视图统一持有：

- 顶部工具栏：最左侧的根节点栏、模式切换、更多操作；新建笔记位于“更多操作”菜单内。搜索固定在各画布右上角，三个模式一致。
- 底部状态栏：显示当前模式的统计或说明。
- 底部缩放控件 `src/ui/footer-controls.ts`：缩小、当前缩放比例、放大、适应画布，以及思维导图专用的“显示全部双链”开关。

## 注意层与卡片

地图一次只展开一层，这一层由**注意层**决定：

- 注意层是当前正在探索的那篇笔记。它**不绘制在画布上**，只出现在顶部根节点栏里：点击它选中并打开右侧笔记，点击它的上级可返回上一层。
- 卡片集合完全等于注意层的直接子节点，有子节点的和无子节点的叶笔记各占一张卡片。没有全局根节点时，顶层由“无父级且有子级”的笔记组成。
- 「未归类」卡只在全局层出现，收纳全库没有父级归属的笔记；下钻后不再出现。
- 下钻：卡片标题右侧的圆形“进入”按钮把注意层下移一层；叶卡片没有下一层，因此不显示该按钮。左上角根节点栏就是面包屑，路径失效时回退到全局根。

## 卡片布局与视觉

- 布局是确定性的：卡片按主题路径稳定排序，按画布宽高比换行打包，卡间距 44、画布边距 80，同一输入永远得到同一布局。
- 卡片是**椭圆**：椭圆按内容块的外接要求放大（内容块 ×1.5），保证主题节点、子节点和更深成员都落在椭圆内部。
- 卡内分级：主题节点（实心椭圆的群落头）+ 直接子节点（带标签的椭圆胶囊）；更深的后代是圆点，折叠时用卡片右上角的圆形箭头展开，展开后卡片变大并重新打包，单卡展开上限 60 篇。
- 成员数量：卡片标题右侧的折叠箭头旁不显示数字，数量在底部状态栏（“显示 X / Y 篇笔记 · 另有 N 篇可展开”）和悬停提示里给出。
- 卡片自适应：节点被拖到卡片外时，卡片会实时扩大把节点包住，标题、底色和边框一起移动；拖动卡片本体则整组节点一起移动。卡片偏移与节点位置分别保存在 `mapLayout.cards` 与 `mapLayout.nodes`。
- 语义缩放：远景只显示椭圆卡片、群落标题、群落头和进入按钮；中景补上一级子节点标签；更深成员始终是圆点，悬停时在旁边显示名称。
- 群落标题、进入按钮和折叠箭头都是屏幕等尺寸的，缩放时始终可读；卡片、连线、节点和标题都画在原生节点自己的绘图表面上，因此平移缩放时不会分层错位。

## 连线分层

- 结构边始终显示，且两端一定在同一张卡片内，只做卡片内部的短曲线（由子节点自己绘制）。
- 跳转边降为次要细线；普通双链默认隐藏，只在选中或悬停该节点时展开显示。
- 注意层节点不在画布上，它与子节点的结构关系由“卡片集合”本身表达，不额外画线。

## 操作

- 单击节点：立即选中并同步右侧笔记（无延迟）；双击沿用笔记编辑弹窗；右键沿用关系管理功能。
- 拖动节点：调整卡内位置并让卡片跟随，松手保存，Esc 取消；拖动与点击用 4px 位移阈值区分，拖动不会打开笔记。
- 拖动卡片空白：整体移动该群落。
- 平移、滚轮缩放沿用原生手势；窗口尺寸变化只重算布局，不会自动重排并强制“适应画布”。
- 搜索覆盖整个知识库：命中当前层以外的笔记时，地图切到它所在的层并高亮居中；命中注意层笔记本身时只高亮顶部导航并打开右侧笔记。

## 编辑与状态

首次创建右侧笔记分栏按 70/30 分配宽度；后续打开笔记及插件重载复用右侧未固定的编辑分栏，并保留用户调整的宽度。编辑和保存由 Obsidian 负责。

`mapLayout`（版本化的卡片偏移、节点位置、视口）与 `mapAttention`（注意层）、`mapSelected` 独立保存。卡片布局结构升级到第 2 版，旧的散乱自动坐标在升级时整体重置，不再沿用。重命名迁移位置、注意层与选择，删除时清理失效条目。思维导图的 `layouts` 不变。

地图不接管原生全局类，模式切换释放不再使用的图谱实例、绘图装饰、监听器与 Worker。原生数据返回范围是显示范围上限，不强行恢复其过滤的笔记。接口不兼容时显示重试提示。

## 验证

`npm run sync` 执行测试、lint、类型检查、构建和安装同步。`output/knowledge-map-runtime-check.js` 在真实 Obsidian 控制台运行集成检查；浏览器旧演示不是知识地图的运行宿主。
